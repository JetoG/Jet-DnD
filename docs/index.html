Jet DnD

Arraste e solte em JavaScript puro, sem dependências. Funciona com mouse, toque e caneta.

Pelo teclado: Tab para focar um card, Espaço para pegar, setas para mover (↑↓ na coluna, ←→ entre colunas), Espaço para soltar e Esc para cancelar.

Documentação Ver no GitHub

Quadro de tarefas

Arraste as tarefas entre as colunas ou mude a ordem dentro de uma coluna. A coluna "Feito" só aceita tarefas que vieram de "Fazendo". No celular, segure o card por um instante para pegá-lo.

Eventos

Mova um card para ver o evento jt-drop aqui.

    Cards criados depois que a página carregou também arrastam.

    Cards com alça

    Só a alça arrasta. O resto do card é texto normal: dá para selecionar e copiar. A alça pode ser qualquer elemento, e um card pode ter mais de uma.

    Lista A

    ⠿
    Selecione este texto
    Clique e arraste aqui para selecionar. Para mover o card, use a alça no canto.
    ⠿
    Copie e cole
    Útil quando o card tem informações que a pessoa precisa copiar, como um código ou um endereço.

    Lista B

    ⠿
    No celular
    Arrastando pela alça, o card pega na hora. Deslizando pelo resto do card, a página rola normalmente.
    Arraste pelo título
    Aqui a alça é o próprio título. Este texto continua selecionável.
    ⠿
    Duas alças
    Dá para arrastar pelo ícone ou pelo título.
